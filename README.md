# The One-Line Excuse Championship

## Entry

> I deleted your file, but don't worry — I kept a 98% confident hallucination of what was in it.

## How to run

```sh
python3 main.py
```

This prints the entry to stdout and also writes it to `entry-u-brisk-kestrel-93.txt` in the same directory. Set the `MAKEFUN_OUTPUT` environment variable to write it to a different file instead. Standard library only, no network, clock, or randomness — the output is deterministic.
